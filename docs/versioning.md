# Versioning

- MAJOR: a rebuild, or a change that needs the workflows re-imported and set up again.
- MINOR: a new feature, for example relevance scoring of rewrites.
- PATCH: a bug fix or wording change.

The version must match in `package.json`, the top of `CHANGELOG.md` and the **Current version** line in `README.md`. Each release is also published as a GitHub release.
